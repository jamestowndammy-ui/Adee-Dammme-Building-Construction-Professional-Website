# Adee & Dammme Building Construction Website

A responsive, multi-section business website built with HTML, CSS, and JavaScript. Designed for GitHub Pages and other static hosting providers.

## Files
- `index.html` — website content and sections
- `styles.css` — responsive layout, typography, and styling
- `script.js` — mobile navigation, current year, and email enquiry draft

## Before publishing
1. Replace the sample phone number `(123) 456-7890` and `+1234567890` with the correct business phone number.
2. Replace `info@example.com` in `index.html` and `script.js` with the correct business email.
3. Replace the placeholder address and verify business hours.
4. Replace the illustrative stock photos with photographs of actual completed projects.
5. Review all claims and services so they accurately represent the business.

The contact form opens the visitor's default email app. It does not save enquiries to a database. To collect enquiries without email software, connect a form service or backend.

## Publish on GitHub Pages
1. Create a **public** GitHub repository, for example `adee-dammme-construction`.
2. Extract this ZIP and upload the four files to the repository's root folder. Ensure `index.html` is at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. GitHub will show the public site URL on the Pages settings screen.

## Image note
This starter site uses illustrative images hosted by Unsplash and Google Fonts loaded from Google Fonts. An internet connection is needed to display those external assets.
